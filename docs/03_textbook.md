## ステージ1: はじめの一歩

### 導入：この知識が何に役立つのか

プログラミングは「コンピューターへの指示書」を書くことです。最初に覚えるのは、結果を画面に表示する print() だけ。これさえ使えれば、以降のすべての学習で「動かして確かめる」ことができます。

### print() で画面に表示する（目安 2分）

Python で画面に何かを表示したいときは print() を使います。括弧 ( ) の中に表示したいものを書きます。

文字（文字列）を表示するときは、必ず引用符 " " か ' ' で囲みます。引用符は「ここからここまでは、ただの文字だよ」という目印です。数値は引用符なしで書けます。

print() は表示したあとに自動で改行（次の行に移動）します。そのため print() を3回書くと、3行に分かれて表示されます。コードは上の行から順番に1行ずつ実行されます。

**用語解説**
- **プログラム / コード**: コンピューターに出す指示を書いたもの。
- **実行**: 書いた指示をコンピューターに動かしてもらうこと。
- **関数**: 決まった仕事をしてくれる命令のこと。print() は「表示する」関数です。
- **文字列**: 文字のならび。引用符で囲んで書く。

**コード例（S01-E1）: いちばん短いプログラム**

```python
print("Hello")
```

実行結果:

```text
Hello
```

コードの解説:
- 1行目: print( ) の中の文字列 "Hello" を画面に表示します。出力に引用符は出ません。

**コード例（S01-E2）: 上から順に実行される**

```python
print("おはよう")
print("こんにちは")
print(2024)
```

実行結果:

```text
おはよう
こんにちは
2024
```

コードの解説:
- 1行目: おはよう を表示して改行します。
- 2行目: 次にこんにちは を表示します。
- 3行目: 数値 2024 は引用符なしで書けます。

### 複数の値・コメント・エラー（目安 2分）

print() の括弧の中に , （カンマ）で区切って複数の値を書くと、間に空白1つを入れて1行に表示されます。カンマ自体は表示されません。

# から行末まではコメントです。人間へのメモで、Python は無視します。コードを一時的に動かしたくないときにも使えます。

Python は大文字と小文字を区別します。print は正しいですが Print は別物としてエラーになります。エラーが出ても失敗ではありません。最後の行に原因のヒントが書かれています。

**用語解説**
- **コメント**: # から行末までのメモ。実行されない。
- **エラー**: Python が指示を理解できなかったときに出る知らせ。原因のヒントが書かれている。
- **構文エラー（SyntaxError）**: 書き方のルール（文法）が間違っているときのエラー。

**コード例（S01-E3）: 複数の値を並べる**

```python
print("Python", "は", "楽しい")
```

実行結果:

```text
Python は 楽しい
```

コードの解説:
- カンマで区切った3つの値が、間に空白1つを入れて1行に表示されます。

**コード例（S01-E4）: コメント**

```python
# あいさつを表示する
print("Hi")  # ここもコメント
```

実行結果:

```text
Hi
```

コードの解説:
- 1行目: コメントだけの行。何も起きません。
- 2行目: print は実行され、# 以降は無視されます。

### よくある間違い

- **大文字で書く**

  ```python
  Print("Hello")
  ```
  - 理由: Python は大文字・小文字を区別するため、Print という名前は存在せず NameError になります。
  - 直し方: print("Hello")

- **引用符の閉じ忘れ・不一致**

  ```python
  print("Hello')
  ```
  - 理由: 引用符は開始と終了で同じ種類にそろえます。そろっていないと SyntaxError になります。
  - 直し方: print("Hello")

- **引用符を付けない**

  ```python
  print(Hello)
  ```
  - 理由: 引用符がない Hello は文字ではなく「名前」として扱われ、NameError になります。
  - 直し方: print("Hello")

- **全角の括弧**

  ```python
  print（"Hello"）
  ```
  - 理由: コードの記号は半角で書きます。全角の括弧は SyntaxError になります。
  - 直し方: print("Hello")

### 理解度チェック
- [ ] print() は画面に表示する
- [ ] 文字列は引用符で囲む（数値は不要）
- [ ] コードは上から順番に実行される
- [ ] , で区切ると空白1つで区切られて1行に表示される
- [ ] # 以降はコメントで実行されない
- [ ] 大文字・小文字は区別される

## ステージ2: データを扱う

### 導入：この知識が何に役立つのか

データに名前を付けておくと、何度でも使い回せて、あとから値を変えることもできます。この名前が「変数」です。計算や文字列の組み立ても、変数と組み合わせると一気にプログラムらしくなります。

### 変数にデータを入れる（目安 3分）

名前 = 値 と書くと、右の値に左の名前を付けて覚えておけます。これを代入といいます。= は数学の「等しい」ではなく「右を左に入れる」という意味です。

同じ名前にもう一度代入すると、前の値は消えて新しい値に置き換わります（上書き）。x += 1 は x = x + 1 の短い書き方で、同じように x -= 1 は x = x - 1 の短い書き方です。

変数名には英字・数字・アンダースコア（_）が使えますが、数字で始めることはできず、空白も入れられません。大文字と小文字は区別されます。

値には種類（型）があります。整数は int、小数は float、文字列は str です。type() で調べられます。

**用語解説**
- **変数**: 値に付けた名前。値を入れておく箱のようなもの。
- **代入**: = で変数に値を入れること。
- **型**: 値の種類。int（整数）、float（小数）、str（文字列）など。

**コード例（S02-E1）: 変数に入れて表示**

```python
name = "Taro"
age = 15
print(name)
print(age)
```

実行結果:

```text
Taro
15
```

コードの解説:
- 1行目: "Taro" に name という名前を付けます。
- 2行目: 15 に age という名前を付けます。
- 3〜4行目: 名前を書くと、入っている値が表示されます（引用符は不要）。

**コード例（S02-E2）: 上書きと +=**

```python
score = 50
score = 80
score += 5
print(score)
```

実行結果:

```text
85
```

コードの解説:
- 2行目: score が 80 に上書きされ、50 は消えます。
- 3行目: score = score + 5 と同じ。80 + 5 = 85 になります。

**コード例（S02-E3）: 型を調べる**

```python
print(type(10))
print(type(3.14))
print(type("10"))
```

実行結果:

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

コードの解説:
- 引用符で囲んだ "10" は数値ではなく文字列（str）です。

### 計算と文字列の組み立て（目安 3分）

計算には + - * / を使います。/ は割り切れても必ず小数（float）になります。// は小数点以下を切り捨てた商、% は余り、** は累乗です。

計算の順番は数学と同じで、* / // % は + - より先です。先に計算したい部分は ( ) で囲みます。

文字列も + で連結でき、* 数 で繰り返せます。変数を文字列に埋め込むには、先頭に f を付けた f"..." の中で {変数名} と書きます（f文字列）。

**用語解説**
- **演算子**: + や * のように、計算や操作を表す記号。
- **連結**: 文字列と文字列をつなげること。
- **f文字列**: f"...{変数}..." の形で、文字列に変数の値を埋め込む書き方。

**コード例（S02-E4）: いろいろな計算**

```python
print(7 + 2)
```

実行結果:


- 3行目: / は小数の結果 3.5 です。
- 4行目: // は切り捨て。7 ÷ 2 の商は 3。
- 5行目: % は余り。7 を 2 で割った余りは 1。
- 7〜8行目: かけ算が先。( ) で順番を変えられます。

**コード例（S02-E5）: 文字列の連結とf文字列**


- 7行目: {name} と {age} の部分が変数の値に置き換わります。

### よくある間違い

- **変数名に空白**

  ```python
  my score = 80
  ```
  - 理由: 変数名に空白は使えず SyntaxError になります。_ でつなぎます。
  - 直し方: my_score = 80

  - 直し方: second = 10

- **/ の結果が整数だと思う**

  ```python
  print(10 / 2)  # 5 と思いがち
  ```
  - 理由: / の結果は割り切れても float なので 5.0 と表示されます。
  - 直し方: 整数の商がほしいときは 10 // 2

- **計算順序の勘違い**

  ```python
  average = a + b / 2
  ```
  - 理由: b / 2 が先に計算されます。足し算を先にしたいなら ( ) で囲みます。
  - 直し方: average = (a + b) / 2

### 理解度チェック
- [ ] = は「右の値を左の名前に入れる」
- [ ] 代入すると前の値は上書きされる
- [ ] 変数名は数字で始められず、空白も使えない
- [ ] / は必ず float、// は切り捨て、% は余り、** は累乗
- [ ] 掛け算・割り算は足し算・引き算より先
- [ ] 文字列は + で連結、* で繰り返し、f文字列で変数を埋め込める

## ステージ3: 条件によって動きを変える

### 導入：この知識が何に役立つのか

ここまでのプログラムは、上から順に全部実行されるだけでした。条件によって動きを変えられると、「合格なら祝う」「雨なら傘」といった判断をプログラムに任せられます。

### 比較とTrue / False（目安 2分）

2つの値を比べると、結果は True（正しい）か False（正しくない）のどちらかになります。これを真偽値（bool 型）といいます。

比較には == （等しい）、 != （等しくない）、 < 、 > 、 <= （以下）、 >= （以上）を使います。等しいかを調べるときは = を2つ重ねた == です。= 1つは代入なので間違えないようにしましょう。

**用語解説**
- **真偽値（bool）**: True か False のどちらかの値。
- **比較演算子**: 2つの値を比べて True / False を返す記号。
- **条件**: True か False になる式。if の判断材料。

**コード例（S03-E1）: 比較の結果を表示**

```python
print(5 > 3)
print(5 == 3)
print(5 != 3)
print("a" == "a")
```

実行結果:

```text
True
False
True
True
```

コードの解説:
- 1行目: 5 は 3 より大きいので True。
- 2行目: 5 と 3 は等しくないので False。
- 4行目: 文字列も == で比べられます。

### if / elif / else と条件の組み合わせ（目安 3分）

if 条件: の下に、字下げ（インデント）した行を書くと、条件が True のときだけ実行されます。条件の末尾のコロン（:）を忘れずに。字下げは半角空白4つが一般的で、同じまとまりの行は同じ深さにそろえます。

else: は「if の条件が成り立たなかったとき」の処理です。さらに細かく分けたいときは elif 条件: を使います。上から順に調べ、最初に成立した1つだけが実行され、残りは調べません。

条件は and（かつ）、or（または）、not（否定）で組み合わせられます。and は両方が True のとき、or はどちらか一方でも True のとき True です。

**用語解説**
- **インデント**: 行頭の字下げ。どの行が if の中かを表す。
- **分岐**: 条件によって実行する処理を切り替えること。
- **ブロック**: 同じ深さにインデントされた、ひとまとまりの行。

**コード例（S03-E2）: if と else**

```python
score = 70
if score >= 60:
    print("合格")
else:
    print("不合格")
print("終わり")
```

実行結果:

```text
合格
終わり
```

コードの解説:
- 2行目: score >= 60 が True なので、字下げした3行目が実行されます。
- 4〜5行目: 条件が成り立たないときの処理。今回は飛ばされます。
- 6行目: 字下げがないので if の外。いつも実行されます。

**コード例（S03-E3）: elif で細かく分ける**

```python
score = 75
if score >= 90:
    print("A")
elif score >= 70:
    print("B")
else:
    print("C")
```

実行結果:

```text
B
```

コードの解説:
- score >= 90 は False。次の elif を調べ、75 >= 70 が True なので B を表示し、残りは調べません。

**コード例（S03-E4）: and と not**

```python
age = 20
has_ticket = True
if age >= 18 and has_ticket:
    print("入場OK")
print(not has_ticket)
```

実行結果:

```text
入場OK
False
```

コードの解説:
- 3行目: 年齢条件とチケット条件の両方が True のときだけ実行されます。
- 5行目: not は True と False を反転します。

### よくある間違い

- **条件に = を使う**

  ```python
  if score = 60:
  ```
  - 理由: = は代入です。等しいかの比較は == を使います（SyntaxError）。
  - 直し方: if score == 60:

- **コロンの付け忘れ**

  ```python
  if score >= 60
      print("合格")
  ```
  - 理由: if・elif・else の行の末尾には : が必要です（SyntaxError）。
  - 直し方: if score >= 60:

- **インデントの忘れ**

  ```python
  if score >= 60:
  print("合格")
  ```
  - 理由: if の中で実行する行は字下げが必要です（IndentationError）。
  - 直し方:     print("合格")  # 半角空白4つ

- **境界値の取り違え**

  ```python
  if score > 60:  # 60点は不合格に
  ```
  - 理由: 「60以上」は >=。> だと60は含まれません。
  - 直し方: if score >= 60:

### 理解度チェック
- [ ] 比較の結果は True / False
- [ ] 等しいかは == 、= は代入
- [ ] if / elif / else の行末には : が必要
- [ ] インデントが if の中を表す
- [ ] elif は上から調べ、最初に成立した1つだけ実行
- [ ] and は両方 True、or はどちらか True

## ステージ4: 処理を繰り返す

### 導入：この知識が何に役立つのか

コンピューターの得意技は「同じことを何度でも正確に繰り返す」ことです。100回の表示も、数行のコードで書けるようになります。

### for と range()（目安 3分）

決まった回数だけ繰り返すには for を使います。for i in range(3): と書くと、字下げした部分が3回実行され、i には 0, 1, 2 が順に入ります。

range(n) は 0 から n-1 まで。range(開始, 終了) は「開始から終了の1つ手前」まで。range(開始, 終了, 間隔) は間隔ごとに進みます。終了の値そのものは含まれない点が最大の注意点です。

合計を求めるときは、ループの前に total = 0 と用意し、ループの中で total += i のように足していきます。

**用語解説**
- **ループ（繰り返し）**: 同じ処理を何度も実行する仕組み。
- **range()**: 連続する整数の列を作る関数。終了の値は含まない。
- **累積**: ループの中で値を足し込んで、合計などを作っていくこと。

**コード例（S04-E1）: range(3)**

```python
for i in range(3):
    print(i)
```

実行結果:

```text
0
1
2
```

コードの解説:
- i には 0, 1, 2 が順に入り、3 は含まれません。字下げした print が3回実行されます。

**コード例（S04-E2）: 開始・終了・間隔**

```python
for i in range(2, 10, 3):
    print(i)
```

実行結果:

```text
2
5
8
```

コードの解説:
- 2 から始まり 3 ずつ増えます。次は 11 ですが 10 未満という条件から外れるので終了します。

**コード例（S04-E3）: 1から5までの合計**

```python
total = 0
for i in range(1, 6):
    total += i
print(total)
```

実行結果:

```text
15
```

コードの解説:
- 1行目: 合計を入れる変数を 0 で用意します。
- 2行目: i は 1,2,3,4,5。
- 3行目: i を total に足します。
- 4行目: 字下げがないのでループの後に1回だけ実行されます。

### while と break / continue（目安 3分）

while 条件: は、条件が True の間、字下げした部分を繰り返します。回数が決まっていないときや、条件で終わりを決めたいときに使います。

条件に使う変数をループの中で変化させないと、条件がずっと True のままになり、プログラムが終わりません（無限ループ）。

break はその場でループを終了し、continue はその回の残りを飛ばして次の回へ進みます。

**用語解説**
- **無限ループ**: 終了条件が成立せず、いつまでも終わらないループ。
- **break**: ループ全体を途中で終了する。
- **continue**: その回の残りを飛ばして、次の回に進む。

**コード例（S04-E4）: カウントダウン**

```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("発射")
```

実行結果:

```text
3
2
1
発射
```

コードの解説:
- 2行目: count が 0 より大きい間、繰り返します。
- 4行目: count を1ずつ減らします。これがないと無限ループです。
- 5行目: ループが終わったあとに1回だけ実行されます。

**コード例（S04-E5）: continue と break**

```python
for i in range(1, 6):
    if i == 3:
        continue
    if i == 5:
        break
    print(i)
```

実行結果:

```text
1
2
4
```

コードの解説:
- i が 3 のとき: continue で print を飛ばし、次の回へ。
- i が 5 のとき: break でループを終了。5 は表示されません。

### よくある間違い

- **終了の値を含むと思う**

  ```python
  for i in range(1, 5):  # 1〜5 のつもり
  ```
  - 理由: range(1, 5) は 1,2,3,4。5 は含まれません。
  - 直し方: for i in range(1, 6):

- **while の中で更新を忘れる**

  ```python
  n = 3
  while n > 0:
      print(n)
  ```
  - 理由: n が変わらないので条件がずっと True。無限ループになります。
  - 直し方: ループの中に n -= 1 を加える

- **合計の初期化忘れ**

  ```python
  for i in range(1, 6):
      total += i
  ```
  - 理由: total を先に 0 で用意していないので NameError になります。
  - 直し方: ループの前に total = 0

- **字下げの位置**

  ```python
  for i in range(3):
      total += i
      print(total)  # 毎回表示される
  ```

## ステージ5: データをまとめる

### 導入：この知識が何に役立つのか

### リストと要素の取り出し（目安 3分）

リストは [ ] の中に値を , で区切って並べて作ります。例: fruits = ["りんご", "みかん", "ぶどう"]。

要素は番号（インデックス）で取り出します。番号は 0 から始まるので、最初の要素は fruits[0] です。-1 は「最後」、-2 は「最後から2番目」を表します。

len(リスト) で要素の数がわかります。要素が3つなら有効な番号は 0, 1, 2 だけで、fruits[3] は範囲外なので IndexError になります。

fruits[1] = "レモン" のように代入すると、その位置の要素が置き換わります。末尾に追加するには fruits.append("もも") を使います。

**用語解説**
- **リスト**: 複数の値を順番に並べてまとめたデータ。
- **要素**: リストの中の1つ1つの値。
- **インデックス**: 要素の位置を表す番号。0から始まる。
- **IndexError**: 存在しない番号で要素を取り出そうとしたときのエラー。

**コード例（S05-E1）: 取り出しと長さ**

```text
3
```

- 3行目: 2番目（3つ目）の要素。
- 4行目: -1 は最後の要素。3行目と同じ結果になります。
- 5行目: 要素の数は 3 です。

**コード例（S05-E2）: 置き換えと追加**

- 4行目: リストをそのまま print すると [ ] 付きで表示されます。

### リストを処理する（目安 3分）

**用語解説**
- **スライス**: リストの一部分を [開始:終了] で取り出すこと。終了は含まない。
- **メソッド**: データに対して . を付けて呼び出す機能。append() など。

## ステージ6: 処理を部品化する

### 導入：この知識が何に役立つのか

同じ処理を何度も書くのは大変で、間違いの元です。処理に名前を付けて「部品」にしておけば、何度でも呼び出せます。この部品が関数です。ここまでに使ってきた print() や len() も関数でした。

### 関数を作って呼び出す（目安 3分）

def 関数名(引数): の下に字下げして処理を書くと、関数を定義できます。定義しただけでは何も実行されず、関数名(...) と書いて呼び出したときに初めて実行されます。

引数は、関数に渡す材料です。def add(a, b): の a と b が引数で、add(3, 4) のように呼び出し時に具体的な値を渡します。

return 値 と書くと、その値を呼び出し元に返し、関数はそこで終了します。返された値は変数に入れたり、他の計算に使ったりできます。

**用語解説**
- **関数**: 名前を付けた処理のまとまり。
- **引数**: 関数に渡す材料の値。
- **戻り値**: 関数が return で返す結果の値。
- **呼び出し**: 関数名(...) と書いて、関数を実行すること。

**コード例（S06-E1）: 引数なしの関数**

```python
def greet():
    print("こんにちは")

greet()
greet()
```

実行結果:

```text
こんにちは
こんにちは
```

コードの解説:
- 1〜2行目: greet という関数を定義するだけ。ここでは表示されません。
- 4〜5行目: 呼び出すたびに実行されるので2回表示されます。

**コード例（S06-E2）: 引数と戻り値**

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
print(add(10, 20))
```

実行結果:

```text
7
30
```

コードの解説:
- 4行目: 3と4を渡し、返ってきた7を result に入れます。
- 6行目: 呼び出しの結果をそのまま print に渡すこともできます。

### print と return、デフォルト引数、ローカル変数（目安 3分）

print は画面に表示するだけで、値は返しません。return がない関数を呼び出すと、結果は None（「何もない」を表す特別な値）になります。計算結果を他の場所で使いたいときは return を使います。

引数に def power(base, exp=2): のように = で初期値を書くと、呼び出し時に省略できます（デフォルト引数）。

関数の中で作った変数は、その関数の中だけで使えるローカル変数です。外にある同じ名前の変数とは別物で、外の値は変わりません。

**用語解説**
- **None**: 「値がない」ことを表す特別な値。return のない関数の結果。
- **デフォルト引数**: 省略したときに使われる初期値付きの引数。
- **ローカル変数**: 関数の中だけで有効な変数。

**コード例（S06-E3）: print と return の違い**

```python

    print(x)

    return x * 2

print(r)
print(double(5))
```

実行結果:

```text
5
None
10
```

コードの解説:
- 7行目: show(5) の中で 5 が表示されます。show は何も返さないので r は None。
- 8行目: None が表示されます。
- 9行目: double は 10 を返し、それを print が表示します。

**コード例（S06-E4）: デフォルト引数**

```python

    return base ** exp

print(power(2, 5))
```

実行結果:

```text

32
```

コードの解説:
- 4行目: exp を省略したので 2 が使われ、3 の2乗で 9。
- 5行目: exp に 5 を渡したので 2 の5乗で 32。

**コード例（S06-E5）: ローカル変数**

```python

    x = 10
    return x

print(f())
print(x)
```

実行結果:

```text
10
100
```

コードの解説:
- 関数 f の中の x は別の変数なので、外の x は 100 のままです。

### よくある間違い

- **定義しただけで呼び出さない**

  ```python
  def greet():
      print("hi")
  ```
  - 理由: 定義だけでは何も起きません。greet() と呼び出す必要があります。
  - 直し方: greet()

- **return の代わりに print**

  ```python
  def area(w, h):
      print(w * h)
  x = area(3, 4) + 1
  ```
  - 理由: area は何も返さない（None）ので、None + 1 で TypeError になります。
  - 直し方: print を return に変える

- **引数の数が合わない**

  ```python
  def add(a, b):
      return a + b
  add(3)
  ```
  - 理由: 引数 b が足りず TypeError になります。
  - 直し方: add(3, 4)

- **return をループの中に書く**

  ```python
  for n in nums:
      s += n
      return s
  ```
  - 理由: return でその場で関数が終了し、最初の1回で終わってしまいます。
  - 直し方: return s をループの外（字下げを戻す）に書く

### 理解度チェック
- [ ] def で定義し、関数名(...) で呼び出す
- [ ] 引数は材料、戻り値は結果
- [ ] return は値を返して関数を終了する
- [ ] print は表示するだけ。return がなければ None
- [ ] デフォルト引数は省略可能
- [ ] 関数内の変数は外とは別物

## ステージ7: エラーを見つけて修正する

### 導入：この知識が何に役立つのか

プログラミングで一番多い時間は、エラーと向き合う時間です。エラーはPythonからの「ここが分かりません」というメッセージで、原因を教えてくれる味方です。読み方のコツを身につければ、怖くなくなります。

### エラーメッセージを読む（目安 3分）

エラーが出ると、長い文章が表示されます（トレースバック）。まず見るのは最後の行です。そこにエラーの種類（例: NameError）と、短い説明が書かれています。途中の行には、エラーが起きた行番号が書かれています。

よく出るエラー: SyntaxError は書き方の間違い（括弧・引用符・コロンなど）。NameError は存在しない名前を使った（スペルミスや代入前）。TypeError は型に合わない操作（例: 文字列 + 数値）。ValueError は型は合っているが値が不適切（例: int("abc")）。ZeroDivisionError は 0 で割った。

エラー名と原因を結びつける習慣をつけましょう。IndentationError は字下げの間違いで、SyntaxError の仲間です。

**用語解説**
- **トレースバック**: エラー発生時に表示される、どこで何が起きたかの記録。
- **デバッグ**: プログラムの間違い（バグ）を見つけて直すこと。
- **バグ**: プログラムの間違い。

**コード例（S07-E1）: NameError の例**

```python
print(Hello)
```

実行結果: `NameError` が発生します（エラーになる例）

コードの解説:
- 最後の行は NameError: name 'Hello' is not defined。Hello という名前が見つからない、という意味です。

**コード例（S07-E2）: TypeError の例**

```python
print("年齢は" + 20)
```

実行結果: `TypeError` が発生します（エラーになる例）

コードの解説:
- 文字列と数値は + でつなげません。最後の行に型の組み合わせが違うという内容が出ます。

**コード例（S07-E3）: ZeroDivisionError の例**

```python
print(10 / 0)
```

実行結果: `ZeroDivisionError` が発生します（エラーになる例）

コードの解説:
- 0 で割ることはできません。

### 型の変換・try/except・デバッグ（目安 3分）

int("5") は文字列を整数に、float("2.5") は小数に、str(20) は文字列に変換します。文字列と数値を + でつなぐときは str() で文字列にそろえます。

エラーが起きるかもしれない処理は try: に入れ、except エラー名: でエラー時の処理を書きます。エラーが起きなければ except は実行されません。

エラーが出ないのに結果が違うときは、print で途中の値を表示して「自分の想像」と「実際の値」を比べます。これが一番基本的なデバッグです。

**用語解説**
- **型変換**: int() や str() などで値の型を変えること。
- **例外**: 実行中に起きるエラーのこと。try / except で受け止められる。
- **論理エラー**: エラーメッセージが出ないが、考え方の間違いで結果が正しくない状態。

## ステージ8: 文字列・データの操作

### 導入：この知識が何に役立つのか

実際のデータは「名前に余計な空白がある」「カンマ区切りの文字列」「名前と点数のセット」など、そのままでは使いにくい形をしています。文字列メソッドと辞書は、そうしたデータを整える基本の道具です。

### 文字列メソッド（目安 3分）

文字列には、. を付けて呼び出す便利なメソッドがあります。strip() は前後の空白を取り除き、upper() / lower() は大文字・小文字にし、replace(古, 新) は置き換え、count(文字) は数えます。

split(",") は文字列を区切り文字で分けてリストにします。引数を省略した split() は空白で区切ります（連続する空白は1つとして扱われます）。逆に "-".join(リスト) は、リストの要素を - でつないだ1つの文字列にします。

文字列はリストと同じように扱える部分もあります。text[0] で1文字目、text[-1] で最後の文字を取り出せ、len(text) で文字数がわかり、for で1文字ずつ取り出せます。

重要: 文字列は変更できません。メソッドは「新しい文字列」を返すだけで、元の変数は変わりません。結果を使いたいときは、変数に代入し直します。

**用語解説**
- **メソッド**: データに . を付けて呼び出す機能。文字列なら s.upper() のように使う。
- **区切り文字**: split で分ける目印にする文字（例: カンマ）。

**コード例（S08-E1）: strip・upper・lower・replace**

```python

print(s.strip()[-1])
```

実行結果:

```text

hello python
12
Hello World
H
n
```

コードの解説:
- 2行目: 前後の空白を除いた文字列。
- 3行目: メソッドをつなげて書けます（strip してから upper）。
- 5行目: 空白を除いた "Hello Python" は12文字です。
- 7〜8行目: 文字列もリストと同じように、[0] で最初の文字、[-1] で最後の文字を取り出せます。

**コード例（S08-E2）: split・join・count・in**

- 1〜2行目: カンマで分けると3要素のリストになります。
- 3行目: リストの要素を - でつなぎます。
- 4行目: 引数なしの split() は空白で区切り、連続する空白も1つ扱い。

**コード例（S08-E3）: 元の文字列は変わらない**

コードの解説:
- 2行目: 大文字の文字列を作って捨てただけ。name は変わりません。
- 4行目: 結果を name に代入し直すと変わります。

### 辞書（ディクショナリ）（目安 3分）

辞書は「キー」と「値」のペアをまとめるデータです。{ } の中に キー: 値 を , で区切って書きます。例えば { "Taro": 20, "Hana": 18 } のように書くと、名前から年齢を引く使い方ができます。

辞書[キー] で値を取り出し、辞書[キー] = 値 で追加または更新します（既にあるキーなら上書き）。キー in 辞書 で存在を調べます。存在しないキーを [ ] で取り出すと KeyError になりますが、辞書.get(キー, 初期値) なら安全です。

for キー, 値 in 辞書.items(): で、すべてのペアを順に取り出せます。辞書は追加した順序を保って表示されます。

**用語解説**
- **辞書（dict）**: キーと値のペアをまとめたデータ。
- **キー**: 値を探すための名前（見出し）。
- **KeyError**: 辞書に存在しないキーで取り出そうとしたときのエラー。

**コード例（S08-E4）: 取り出し・追加・更新**

```python
ages = {"Taro": 20, "Hana": 18}
print(ages["Taro"])
ages["Ken"] = 25
ages["Hana"] = 19
print(ages)
print("Ken" in ages)
print(len(ages))
```

実行結果:

```text
20
{'Taro': 20, 'Hana': 19, 'Ken': 25}
True
3
```

コードの解説:
- 3行目: 新しいキー Ken を追加。
- 4行目: 既にあるキー Hana は上書き（追加されません）。
- 5行目: 辞書をそのまま print すると { } 付きで表示されます。

**コード例（S08-E5）: get と items**

```python
stock = {"apple": 3, "banana": 5}
print(stock.get("apple"))
print(stock.get("grape", 0))
for key, value in stock.items():
    print(key, value)
```

実行結果:

```text
3
0
apple 3
banana 5
```

コードの解説:
- 3行目: キーがなければ、2つ目の引数（0）を返します。
- 4行目: items() はキーと値のペアを順に取り出します。

**コード例（S08-E6）: 文字を数える**

```python
counts = {}
for ch in "abca":
    if ch in counts:
        counts[ch] += 1
    else:
        counts[ch] = 1
```

- 2行目: 文字列も for で1文字ずつ取り出せます。
- 3〜6行目: すでにあれば +1、なければ 1 で新しく作ります。

### よくある間違い

- **メソッドの結果を使わない**

  ```python

  name.upper()

  ```
  - 理由: メソッドは新しい文字列を返すだけで、元の変数は変わりません。
  - 直し方: name = name.upper()

  - 直し方: print(stock.get("grape", 0))

  - 理由: 辞書をそのまま for に渡すとキーだけが取り出され、展開に失敗します。

## ステージ9: ミニプログラムを読み解く

### プログラムの読み方とおみくじ（目安 3分）

長いコードを読むコツは、変数の値を1行ずつ追うことです。紙やメモに「変数名と今の値」を書き出しながら、上から順に進みます。迷ったら、まず if の条件が True か False かを判断し、実行される行だけを追います。

おみくじのように結果を運で決めるときは、random モジュールを使います。import random と書き、random.randint(1, 6) とすると 1 から 6 までの整数がランダムに返ります。range と違って、終わりの 6 も含まれます。

ランダムな値は実行のたびに変わり、結果を確定できません。そこで、n = 7 のように値を決めて、処理の部分だけを確認するのが基本です。

**用語解説**
- **トレース**: 変数の値の変化を、1行ずつ追いかけて確かめること。
- **モジュール**: 便利な機能を集めた部品。import で使えるようにする。
- **random.randint(a, b)**: a 以上 b 以下の整数をランダムに1つ返す。

**コード例（S09-E1）: おみくじの判定部分**

```python
n = 7

else:
    result = "小吉"
print(result)
```

実行結果:

```text
中吉
```

コードの解説:
- n = 7 は 9 以上ではなく、5 以上なので elif の中吉が選ばれます。

**コード例（S09-E2）: randint の範囲**


実行結果:


コードの解説:
- n の値は毎回変わりますが、必ず 1 以上 6 以下なので、最後の式はいつも True になります。

### 簡易計算機と集計（目安 3分）

簡易計算機は、関数に2つの数と計算の種類（演算子の文字）を渡し、if / elif で処理を切り替える作りになります。対応していない種類は else で知らせます。

成績の集計では、リストを for で順に調べ、if で条件に合うものを数えたり、合計したりします。辞書とリストを組み合わせると、買い物かごの合計のような処理も書けます。

**用語解説**
- **演算子**: + や - など計算を表す記号。ここでは文字列 "+" として関数に渡す。
- **集計**: データを数えたり合計したりして、全体の特徴をまとめること。

**コード例（S09-E3）: 簡易計算機**

## ステージ10: 総合演習

### 導入：この知識が何に役立つのか

### 分解して考える・ループの入れ子（目安 3分）

プログラムを書く前に、「何を受け取り（入力）、どう処理し（処理）、何を返す・表示するか（出力）」を言葉で書きます。次に、小さな値（例: リストが [3, 9, 4]）で、手で計算してみます。これが設計図になります。

ループの中にループを書くこともできます（入れ子）。外側のループが1回進むごとに、内側のループが最初から最後まで回ります。字下げの深さで、どのループの中かを判断します。

文字列に文字を足し込むときは line += "*" のように書きます。ステージ2の += は文字列にも使えます。

**用語解説**
- **入れ子（ネスト）**: ループや if の中に、さらにループや if を書くこと。
- **境界値**: ちょうど切り替わる値や、端の値（0、1つだけ、空など）。

**コード例（S10-E1）: 入れ子のループ**

```python
for i in range(1, 4):
    line = ""
    for j in range(i):
        line += "*"
    print(line)
```

実行結果:

```text
*
**
***
```

コードの解説:
- 外側: i は 1, 2, 3。
- 内側: i 回だけ * を足します。i=2 なら ** になります。
- 5行目: 内側のループが終わるたびに1行表示されます。

**コード例（S10-E2）: 最大値を求める**

```python
nums = [3, 9, 4]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print(biggest)
```

実行結果:

```text
9
```

コードの解説:
- 2行目: まず最初の要素を暫定の最大値とします。
- 4〜5行目: もっと大きい値が見つかったら更新します。

### 定番パターン: FizzBuzz と回文（目安 3分）

FizzBuzz は、3の倍数なら Fizz、5の倍数なら Buzz、両方の倍数（15の倍数）なら FizzBuzz、それ以外は数字を返す有名な練習問題です。15 の倍数は 3 の倍数でもあるので、必ず 15 の判定を最初に書きます。

回文は、前から読んでも後ろから読んでも同じ文字列（level など）です。i 番目の文字と、後ろから i 番目の文字（text[-1 - i]）が同じかをくり返し確かめます。一つでも違えば False です。

どちらも、新しい文法はありません。条件の順序と、境界の値（空の文字列、1文字など）に気を付ければ、これまでの知識で書けます。

**用語解説**
- **FizzBuzz**: 倍数の判定を練習する定番の課題。
- **回文**: 前から読んでも後ろから読んでも同じになる文字列。

**コード例（S10-E3）: FizzBuzz の関数**

```python
def fizzbuzz(n):
    if n % 15 == 0:
        return "FizzBuzz"
    elif n % 3 == 0:
        return "Fizz"
    elif n % 5 == 0:
        return "Buzz"
    else:
        return str(n)

for i in range(1, 6):
    print(fizzbuzz(i))
```

実行結果:

```text
1
2
Fizz
4
Buzz
```

コードの解説:
- 2行目: 15 の倍数を最初に判定します。
- 8行目: それ以外は数字を文字列にして返します。

**コード例（S10-E4）: 回文の判定**

```python
def is_palindrome(text):
    for i in range(len(text)):
        if text[i] != text[-1 - i]:
            return False
    return True

print(is_palindrome("level"))
print(is_palindrome("abc"))
```

実行結果:

```text
True
False
```

コードの解説:
- 3行目: 前から i 番目と、後ろから i 番目を比べます（i=0 なら最初と最後）。
- 4行目: 1つでも違えばすぐ False を返して終了します。
- 5行目: 最後まで違いがなければ True です。

### よくある間違い

- **FizzBuzz の判定順序**

  ```python
  if n % 3 == 0:
      return "Fizz"
  elif n % 15 == 0:
      return "FizzBuzz"
  ```
  - 理由: 15 は3の倍数でもあるので、最初の条件で Fizz になってしまいます。15 を先に判定します。
  - 直し方: n % 15 == 0 を最初にする

- **最大値の初期値を 0 にする**

  ```python
  biggest = 0
  ```
  - 理由: すべて負の数のリストだと、本当の最大値より大きい 0 が残ってしまいます。最初の要素を使うのが安全です。
  - 直し方: biggest = nums[0]

- **return をループの内側に書きすぎる**

  ```python
  for ...:
      if ...:
          return False
      else:
          return True
  ```
  - 理由: 最初の1回で結果が確定してしまいます。True は、ループが終わってから返します。
  - 直し方: return True をループの外に出す

- **境界値を試さない**

  ```python
  （通常の値だけで確認する）
  ```
  - 理由: 空・1つだけ・ちょうどの値でも動くか確認します。
  - 直し方: 端の値で手動チェックする
