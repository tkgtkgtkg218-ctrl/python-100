# 8. Webアプリの画面・機能仕様（試作版）

方針: **教材の読みやすさと、問題を解く体験を最優先**。アカウント、ランキング、課金、SNS共有、通知などは試作では作らない。進捗は端末内（localStorage / IndexedDB）に保存する。

## 8.1 画面遷移

```
[ステージ一覧] ──選択──▶ [レッスン(セクション1→2)] ──「問題へ」──▶ [問題回答] ⇄ [フィードバック]
      ▲                                                                   │ 10問終了
      │                                                                   ▼
      └──────────── 「ステージ一覧へ」 ◀──────── [ステージクリア / 結果] ──▶ 次のステージのレッスン
      │
      └──▶ [学習進捗]（どの画面からもヘッダーのリンクで開く）
```

## 8.2 画面一覧

### (1) ステージ一覧画面
| 項目 | 内容 |
|---|---|
| 表示項目 | 10ステージのカード: ステージ番号・名称・サブタイトル・学習目標（1〜2行）・進捗（n/10問）・星（0〜3）・状態（未解放🔒 / 学習可 / クリア済） |
| ユーザー操作 | カードをタップ → レッスンへ。🔒カードは「ステージN-1をクリアすると開きます」と表示。「続きから」ボタン（最後に開いた問題へ） |
| 必要データ | `curriculum.json: stages[].{id, number, title, subtitle, learning_goals, unlock_condition}`、進捗データ |
| 遷移 | → レッスン画面 / → 学習進捗画面 |

### (2) 教科書・レッスン画面
| 項目 | 内容 |
|---|---|
| 表示項目 | 導入文 → セクション（本文・用語解説・コード例＋実行結果＋行ごとの解説）→ よくある間違い → 理解度チェック → 次の問題への導入。セクション単位でページ分割（約2〜3分）。上部に進捗バー（セクション1/2） |
| ユーザー操作 | 「次へ」「前へ」、用語のタップで解説を展開、コード例のコピー、「問題を解く」ボタン、レッスンをスキップして問題へ |
| 必要データ | `lessons.json: lessons[]`（`stage_id` で引く） |
| 遷移 | → 問題回答画面（Q1、または未回答の最初の問題） / → ステージ一覧 |
| 補足 | `expected_error` を持つコード例は、出力欄に「エラーになります（NameError）」のようにエラー名を赤系の枠で表示 |

### (3) 問題回答画面
| 項目 | 内容 |
|---|---|
| 表示項目 | 「ステージ3 ・ 4/10」、タイトル、問題文、コード（等幅・行番号）、回答UI、ヒントボタン、「教科書を見る」リンク、「回答する」ボタン |
| 回答UI | `answer_mode` により切替: **choice**=3つの選択肢（`choice_format=code` なら等幅）／ **text**=穴埋めは空欄ごとの入力欄をコード中に埋め込み表示、出力予測は複数行テキストエリア、入力式の間違い探しは対象行だけが編集可能（インデントは固定）／ **code**=簡易コードエディタ（`prefix_code` を読み取り専用で先頭表示、`starter_code` を初期値）＋「実行して試す」ボタン |
| ユーザー操作 | 回答選択・入力、ヒント表示（段階表示1回）、実行して試す（code のみ。自分の出力を見るだけで採点しない）、回答する |
| 必要データ | `questions.json: questions[]`（`answer` は採点時のみ使用。クライアントに出す場合は難読化せず、「答えはブラウザの開発者ツールで見える」前提の学習アプリとして割り切る。サーバー採点なら `answer` を配信しない） |
| 遷移 | 回答 → フィードバック |
| 補足 | 非公開テストの入力は画面に出さない。公開テストの `call` に `sorted(...)` など未習の関数が含まれる場合（PY-080, PY-100）は、画面では「関数を呼び出して結果を確認します」のような平易な表示にする（データ上は `call` のまま採点に使う） |

### (4) 正解・不正解のフィードバック画面（または回答画面内のパネル）
| 項目 | 内容 |
|---|---|
| 表示項目 | ○/× と `feedback_correct` / `feedback_incorrect`、**あなたの回答**と**正解**の並列表示、`rationale`、`explanation`、不正解の選択肢を選んだ場合はその `wrong_answer_reasons[選択ID]`、入力式で `common_mistakes` に一致した場合はその `reason`、コード作成では失敗した公開テストの「期待/実際」 |
| ユーザー操作 | 「次の問題へ」、不正解時は「もう一度挑戦」（同じ問題をやり直し）、「教科書の該当箇所へ」 |
| 必要データ | 上記の問題データ、採点結果 |
| 遷移 | → 次の問題 / 最終問題なら → ステージクリア画面 |
| 補足 | 不正解でも責める表現を使わない。1回目の回答だけがクリア判定に数えられることを小さく表示 |

### (5) ステージクリア（結果）画面
| 項目 | 内容 |
|---|---|
| 表示項目 | 結果（1回目の正解数 n/10、星）、クリア/未クリア、間違えた問題一覧（タイトルと概念）、獲得した理解度チェック、次のステージの学習目標 |
| ユーザー操作 | 「次のステージへ」（クリア時）、「間違えた問題を復習」、「このステージをやり直す」、「ステージ一覧へ」 |
| 必要データ | `clear_condition`、回答履歴 |
| 遷移 | → 次のステージのレッスン / → 復習（間違えた問題だけ）/ → ステージ一覧 |

### (6) 学習進捗画面
| 項目 | 内容 |
|---|---|
| 表示項目 | 全体の進捗（クリアステージ数/10、解いた問題数/100）、ステージ別の正答率と星、概念別の習得度（`concepts` ごとの正答率。低いものを「復習のおすすめ」に表示）、学習日数 |
| ユーザー操作 | ステージを選んで再挑戦、「データを消去」（確認ダイアログ付き） |
| 必要データ | 進捗データ＋`questions.json: concepts` |
| 遷移 | → ステージ一覧 / レッスン / 復習 |

## 8.3 機能一覧（試作の必須範囲）

| 機能 | 仕様 | データ |
|---|---|---|
| 問題の表示 | `answer_mode`・`type` に応じたUI。コードは等幅・インデント保持。HTMLエスケープ必須 | `questions[]` |
| 回答の入力 | 選択、空欄入力、複数行入力、コードエディタ。IME入力（全角）を許容 | — |
| 自動採点 | `docs/05_grading_spec.md` に従う。A案（選択・穴埋め・予測のみ自動、コード作成は自己採点）から開始し、B案（Pyodide + Worker）へ | `grading`, `answer` |
| 正解・不正解の表示 | 8.2(4) | `feedback_*` |
| 解説の表示 | `rationale` → `explanation` → 誤答の理由 | `explanation`, `wrong_answer_reasons`, `common_mistakes` |
| 次の問題への遷移 | `number_in_stage` 順。最終問題の後はステージクリア画面 | `number_in_stage` |
| ステージクリア判定 | 1回目の回答での正解数 ≥ `required_correct`（7）。星は 7/9/10 問 | `clear_condition` |
| 学習進捗の保存 | 回答のたびに保存（下記スキーマ）。ブラウザのデータ消去で失われる旨を設定画面に表示 | 進捗データ |
| 再挑戦機能 | (a) 問題の再挑戦: 同じ問題をやり直せる（クリア判定には数えない）。(b) ステージのやり直し: 新しい「挑戦(attempt)」を開始。過去の挑戦履歴は残す。(c) 間違えた問題の復習モード | 進捗データ |

## 8.4 進捗データの推奨スキーマ（アプリ側）

```json
{
  "version": 1,
  "courseId": "python-basics-ja",
  "stages": {
    "S01": {
      "status": "cleared",
      "bestStars": 2,
      "attempts": [
        {
          "attemptId": 1,
          "startedAt": "2026-10-26T09:00:00+09:00",
          "answers": {
            "PY-001": {"firstCorrect": true, "tries": 1, "lastAnswer": "c2", "hintUsed": false}
          }
        }
      ]
    }
  },
  "lastPosition": {"stageId": "S02", "questionId": "PY-013"}
}
```

- クリア判定は `attempts[最新].answers[*].firstCorrect` の合計で行う。
- 概念別の習得度は `questions[].concepts` と `firstCorrect` から計算できる（保存不要）。

## 8.5 非機能・やらないこと

- 目標表示速度: ステージ一覧・レッスンは初回ロード後すぐ（JSON 3ファイルの合計は約370KB（indent付き）。圧縮後サイズと表示速度は未計測）。
- アクセシビリティ: 色だけで○×を示さない（アイコン＋文言）。キーボード操作で選択・回答可能。コードのコントラスト比を確保。
- 試作では作らない: ユーザー登録、クラウド同期、ランキング、ガチャ、学習リマインド通知、自由なコード実行環境（プレイグラウンド）、他言語。
- 将来の拡張: 復習の間隔反復、Pyodide による「実行して試す」、他言語コースの追加（`course.id` を分けて同形式のJSONを追加）。
