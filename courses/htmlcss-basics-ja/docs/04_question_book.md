
- 前提: ステージ1〜10で学習した内容のみを前提とする。HTML（マークアップ言語）と CSS（スタイルシート言語）だけを扱い、JavaScript は使わない。

**問題**: 幅 800px の箱が、スマホ（画面幅 400px）で、画面からはみ出してしまいます。画面の幅に収まるようにするには、どうすればよいですか？

HTML（あらかじめ用意されているもの）:

```html
<div class="photo"></div>
```

```css
.photo {
  width: 800px;
  height: 100px;
  background-color: gray;
}
```

- 検証方法: ブラウザで `css` として読み込み、式 `document.querySelector('.photo').getBoundingClientRect().width <= document.documentElement.clientWidth` が true になることを確認（画面幅 400px）
- c1) width を、もっと大きい値（1200px など）にする
  - 誤りの理由: 幅を大きくすると、もっとはみ出します。画面より広くならないように、上限を決めます。
- c2) body に overflow: hidden を指定する
  - 誤りの理由: はみ出した部分を隠すだけで、箱は小さくなりません。見える範囲が切れてしまう（内容が見えなくなる）ので、適切な対処ではありません。
- c3) max-width: 100% を追加する ✅

**正解の根拠**: max-width: 100% は、親の幅を超えないように、上限を決める指定だから。

**解説**: width: 800px だけだと、画面の幅が 800px より狭くても、800px のままです。max-width: 100% を足すと、親の幅（画面の幅）を超えず、狭い画面では、親の幅に縮みます。画像にも、同じ指定を使います。

- ヒント: 親の幅を超えないようにする、上限の指定です。
- 正解後: 正解！max-width: 100% で上限を決めます。
- 不正解後: 惜しい！幅の「上限」を決める指定を使います。

### HC-096 ステージ10-6: かっこのないメディアクエリ

```html
<p>テスト</p>
```

```css
@media max-width: 600px {
  p {
    color: red;
  }
```

**正解（1行目の置換候補）**: `@media (max-width: 600px) {` / `@media (max-width:600px) {` / `@media (max-width: 600px){` / `@media (max-width:600px){`

```css
@media (max-width: 600px) {
```

- 正解後: 正解！条件はかっこで囲みます。

### HC-097 ステージ10-7: 折り返したときの行数

- 形式: 表示の予測 ／ 難易度: 3 ／ 概念: flex-wrap、レスポンシブ ／ 採点: 出力比較（正規化あり）
- 前提: ステージ1〜10で学習した内容のみを前提とする。HTML（マークアップ言語）と CSS（スタイルシート言語）だけを扱い、JavaScript は使わない。

**問題**: 次の HTML と CSS を組み合わせたページを、画面の幅 500px で表示したとき、アイテムは何行に並びますか？数字だけを入力してください。（body の標準の余白は 8px なので、コンテナの幅は 484px です）

HTML（あらかじめ用意されているもの）:

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
.item {
  width: 200px;
  height: 50px;
}
```

- 検証方法: ブラウザで `css` として読み込み、式 `new Set(Array.from(document.querySelectorAll('.item')).map(function (e) { return Math.round(e.getBoundingClientRect().top); })).size` の値を確認（画面幅 500px）
**正解（答え）**:

```text
2
```

- よくある誤答 `1`: 200px × 3 = 600px は、コンテナの幅 484px に収まりません。flex-wrap: wrap があるので、収まらない分は折り返します。
- よくある誤答 `3`: 200px × 2 = 400px は 484px に収まるので、2つは同じ行に並びます。

**正解の根拠**: 1行に収まるのは2つ（400px）までで、3つ目は次の行に折り返すから。

**解説**: flex-wrap: wrap を指定すると、アイテムが親の幅に収まらないとき、次の行に折り返します。指定がないと、標準では、アイテムが縮んで1行に収まろうとします。画面の幅によって、行数が変わるので、レスポンシブな並べ方に便利です。

- ヒント: 484px の中に、200px のアイテムが、何個収まりますか？
- 正解後: 正解！収まらないアイテムは折り返します。
- 不正解後: 惜しい！1行に収まる個数を計算しましょう。

### HC-098 ステージ10-8: モバイルファースト

- 形式: 3択 ／ 難易度: 2 ／ 概念: モバイルファースト、min-width ／ 採点: 選択肢ID一致
- 前提: ステージ1〜10で学習した内容のみを前提とする。HTML（マークアップ言語）と CSS（スタイルシート言語）だけを扱い、JavaScript は使わない。

**問題**: 「モバイルファースト」の考え方として、正しいものはどれですか？

- c1) まず PC 向けのスタイルを書き、スマホ向けは、max-width のメディアクエリですべて作り直す
  - 誤りの理由: それは、デスクトップファーストの考え方です。モバイルファーストは、スマホ向けを基本にします。
- c2) まずスマホ向けのスタイルを基本として書き、広い画面向けを、min-width のメディアクエリで追加する ✅
- c3) スマホ向けのページと PC 向けのページを、別々の HTML ファイルとして、2つ作る
  - 誤りの理由: レスポンシブデザインは、1つの HTML を、CSS で、画面の幅に合わせて切り替えます。ファイルを分ける必要はありません。

**正解の根拠**: スマホ向けを基本にして、広い画面で必要な変更だけを、min-width で足す設計だから。

**解説**: スマホ向けは、縦並びの、シンプルなレイアウトが基本なので、基本のスタイルが少なくなります。広い画面で横並びにしたいところだけを、@media (min-width: …) で追加します。

- ヒント: Mobile First は、「スマホを最初に」という意味です。
- 正解後: 正解！スマホ向けを基本にします。
- 不正解後: 惜しい！何を最初に書くか、考えましょう。


### HC-100 ステージ10-10: レスポンシブなページを作る

- 形式: HTML/CSSを書く ／ 難易度: 5 ／ 概念: viewport、メディアクエリ、Flexbox、ページ制作、セマンティクス ／ 採点: テストケース実行
- 前提: ステージ1〜10で学習した内容のみを前提とする。HTML（マークアップ言語）と CSS（スタイルシート言語）だけを扱い、JavaScript は使わない。

**問題**: 次の仕様のページを、HTML と CSS（style 要素）で書いてください。  
【HTML】文書型宣言・lang="ja"・UTF-8 の meta・viewport の meta（content に width=device-width を含める）・title（空でない）。body の中に、header（見出し1を含む）、main（その中に .cards。.cards の中に、見出し2と段落を持つ .card を3つ）、footer。  
【CSS】画面の幅が 600px 以上のときは、3つの .card を横一列（幅は等分）に並べる。599px 以下のときは、縦に並べる（左端はそろえる）。どの幅でも、横スクロールは出さない。

初期コード:

```html
<!doctype html>

  <!-- ここに書きましょう -->
</head>

</body>

```

**模範解答**:

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>レスポンシブなページ</title>

    body { margin: 0; font-family: sans-serif; }
    header, footer { padding: 16px; background-color: #333; color: white; }
    main { padding: 16px; }
    .cards { display: flex; flex-direction: column; gap: 16px; }
    .card { padding: 16px; border: 1px solid #ccc; }
    @media (min-width: 600px) {
      .cards { flex-direction: row; }
      .card { flex: 1; }
    }
  </style>
</head>
<body>
  <header>
    <h1>ぼくのサイト</h1>
  </header>
  <main>
    <div class="cards">
      <div class="card"><h2>カードA</h2><p>説明A</p></div>
      <div class="card"><h2>カードB</h2><p>説明B</p></div>
      <div class="card"><h2>カードC</h2><p>説明C</p></div>
    </div>
  </main>
  <footer>
    <p>© 2026</p>
  </footer>
</body>
</html>
```
