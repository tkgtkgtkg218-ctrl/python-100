## S01 ステージ1: HTMLの基本構造

*要素・タグ・属性と、HTML文書の骨組み*

### 学習目標
- HTML がWebページの構造と意味を表すマークアップ言語であることを説明できる
- 要素・開始タグ・終了タグ・内容・属性という用語を正しく使い分けられる
- <!doctype html>・html・head・body の役割を説明できる
- 最小の HTML 文書を自分で書ける
- ブラウザが空白・改行・コメントをどう扱うかを説明できる

### 学習前に必要な知識
- 特になし（テキストエディタでファイルを保存し、ブラウザで開ければ十分です）

### 教材で説明する項目
- HTML とは（マークアップ言語。CSS・JavaScript との役割の違い）
- 要素、開始タグ、終了タグ、内容
- 属性と属性値
- 文書型宣言 <!doctype html>
- html・head・body、meta charset、title
- コメント、空白と改行の扱い

### つまずきやすいポイント
- HTML は「実行」するものではなく、ブラウザが読み取って表示するもの
- 終了タグの書き忘れ（ブラウザが推測して直すため、意図と違う構造になる）
- <!doctype html> を書かないと、ブラウザが古い互換モードで表示する
- ソースの改行や連続した空白は、そのままは表示されない
- 属性値は引用符で囲む

## S02 ステージ2: 見出し・段落・テキスト

*文章の構造を表す要素と、ブロック・インライン*

### 学習目標
- 見出し（h1〜h6）と段落（p）で、文章の構造を表せる
- 強調（strong / em）、改行（br）、区切り（hr）、まとまり（div / span）を使い分けられる
- 要素の意味（セマンティクス）と見た目を区別して考えられる
- ブロックレベルの要素とインラインの要素の、表示の違いを説明できる
- < や & を文字として表示する文字参照（&lt; &amp; など）を使える

### 学習前に必要な知識
- HTML の基本構造・要素と属性（ステージ1）

### 教材で説明する項目
- 見出し h1〜h6 と、見出しの階層
- 段落 p と、改行 br・区切り線 hr
- 強調 strong / em（意味）と、b / i（見た目だけ）
- div と span（意味を持たないまとまり）
- ブロックとインライン
- 文字参照（&lt; &gt; &amp;）

### つまずきやすいポイント
- 文字を大きくしたいから h1 を使う（見出しは構造のために使う。大きさは CSS で変える）
- 段落の間を空けるために <br> を並べる（段落は p 要素で分ける）
- p の中に見出しなどのブロック要素を入れる（p は途中で自動的に閉じられてしまう）
- br は空要素。</br> と書くと、改行が2つになってしまう
- < をそのまま書くと、タグの始まりと誤解される（&lt; と書く）

## S03 ステージ3: リンクと画像

*a 要素と img 要素、パスの書き方、alt 属性*

### 学習目標
- a 要素と href 属性でリンクを作れる
- 絶対URL・相対パス・ページ内リンク・メールリンクを書き分けられる
- target="_blank" と rel="noopener noreferrer" の意味を説明できる
- img 要素で画像を表示し、alt・width・height を正しく指定できる
- figure と figcaption で、画像に説明を付けられる

### 学習前に必要な知識

- alt の書き方
- figure と figcaption

### つまずきやすいポイント
- リンク先は href（src ではない）、画像のファイルは src（href ではない）
- 相対パスは、いま書いている HTML ファイルの場所が基準
- リンクの文字を「こちら」にしない（リンク先が分かる文字にする）
- alt を書かない・「画像」などの無意味な文字にしない
- target="_blank" を使うときは rel="noopener noreferrer" も付ける

## S04 ステージ4: リストとページ構造

*ul / ol / li、header・nav・main・footer などの構造を表す要素*

### 学習目標
- ul・ol・li で、順序のないリスト・順序のあるリストを書き分けられる
- リストを入れ子にする正しい書き方を説明できる
- header・nav・main・section・article・footer などで、ページの構造を表せる
- div と、意味を持つ構造の要素を使い分けられる
- ナビゲーションを「リンクのリスト」として書ける

### 学習前に必要な知識

### つまずきやすいポイント

- main はページに1つ。何でも div で書かず、意味のある要素を選ぶ
- リストは「見た目の点」のためではなく、「項目が並んでいる」という構造のために使う

## S05 ステージ5: フォーム

*form・input・label・select・textarea・入力チェック*

### 学習目標
- form 要素と、action・method 属性の役割を説明できる
- input の type 属性で、入力欄の種類を使い分けられる
- label を for と id で入力欄に関連付けられる
- radio（name でグループ化）・checkbox・select・textarea を使える
- required・type="email" などの、ブラウザの入力チェックの仕組みを説明できる

### 学習前に必要な知識
- HTML の基本構造（ステージ1）
- 文章・リンク・リスト・構造の要素（ステージ2〜4）

### 教材で説明する項目
- form・action・method（GET / POST）
- input の種類（text・email・password・number・checkbox・radio）
- name 属性とデータの送信
- label と for / id
- select・option・textarea
- required・placeholder・minlength・min / max（入力チェック）
- button と type="submit"

### つまずきやすいポイント
- label の for と、input の id が一致していないと、関連付けられない
- radio は name を同じにすると1つのグループになる。name が違うと、複数選べてしまう
- name 属性がない入力欄の値は、送信されない
- placeholder は、ヒントにすぎない（label の代わりにしない）
- type に存在しない値を書くと、text として扱われる
- 属性値は引用符で囲む（空白を含む値は、引用符がないと途中で切れる）

## S06 ステージ6: CSSの基本

*ルールの書き方・セレクタ・文字色と背景色・優先順位*

### 学習目標
- CSS が、見た目を指定するスタイルシート言語であることを説明できる
- セレクタ・プロパティ・値・宣言ブロックという用語を使って、CSS のルールを読める
- style 要素・外部ファイル（link）・style 属性の3つの適用方法を説明できる
- 要素・クラス・id のセレクタで、スタイルを適用する対象を選べる
- color と background-color で、文字色と背景色を指定できる
- スタイルの優先順位（詳細度・後勝ち）と、継承の基本を理解する

### 学習前に必要な知識
- HTML の基本（ステージ1〜5）。特に、要素・属性（class・id）

### 教材で説明する項目
- CSS とは（スタイルシート言語）
- ルールの書き方（セレクタ { プロパティ: 値; }）
- 適用方法（style 要素・link・style 属性）
- 要素・クラス・id セレクタ
- color と background-color（色の名前）
- 優先順位と継承
- コメント /* */

### つまずきやすいポイント
- 宣言の終わりの ; を忘れると、次の宣言までまとめて無効になる
- プロパティ名の綴り間違い（color を colour と書くなど）は、エラーにならず無視される
- class は .、id は # をセレクタの先頭に付ける
- 同じ要素に複数のルールが当たるときは、詳細度（id > class > 要素）と、後に書いたものが優先される
- 文字色などは、子要素にも引き継がれる（継承）。背景色などは、引き継がれない

## S09 ステージ9: Flexbox

*display: flex、主軸と交差軸、並べ方・揃え方・伸び縮み*

### 学習目標
- display: flex で、子要素を横一列に並べられる
- Flex コンテナ（親）と Flex アイテム（子）、主軸と交差軸という用語を使える
- flex-direction・justify-content・align-items・gap・flex-wrap を使える
- flex（flex: 1 など）で、アイテムの幅を割り振れる
- ナビゲーションバー・カードの横並び・中央寄せを Flexbox で作れる

### 学習前に必要な知識
- ボックスモデル・display（ステージ8）
- CSS の基本・セレクタ（ステージ6〜7）

### 教材で説明する項目
- display: flex と Flex コンテナ・Flex アイテム
- 主軸と交差軸、flex-direction
- justify-content（主軸方向の並べ方）
- align-items（交差軸方向の揃え方）
- gap と flex-wrap
- flex（flex-grow）によるアイテムの伸び縮み

### つまずきやすいポイント
- display: flex は、並べたい要素の「親」に書く（子ではない）
- justify-content や align-items は、display: flex を指定した親でないと効かない
- flex-direction: column にすると、主軸が縦になり、justify-content と align-items の向きが入れ替わる
- align-items が縦方向の中央揃えに効くのは、親に height（高さ）がある場合
- display の値は flex（flexbox や inline-flexbox などは存在しない）

## S10 ステージ10: レスポンシブデザインと簡単なページ制作

*viewport・メディアクエリ・柔軟なレイアウト・ページを組み立てる*
