## S01 ステージ1: 変数とデータ型

*console.log、let / const、データ型*

### 学習目標
- JavaScript がブラウザの中で動くプログラミング言語であることを説明できる
- console.log で値をコンソールに表示できる
- let と const で変数を宣言し、値を入れたり変更したりできる
- 数値・文字列・真偽値・undefined・null というデータ型を区別できる
- typeof で型を調べられる
- 最初のエラー（ReferenceError / TypeError）の原因を推測できる

### 学習前に必要な知識
- 特になし（HTML と CSS を少し知っていると、ステージ8以降が分かりやすくなります）

### 教材で説明する項目
- JavaScript とは（HTML・CSS との役割の違い）
- 動かす場所（<script> タグ、開発者ツールのコンソール）
- console.log とコメント
- let と const
- データ型（number / string / boolean / undefined / null）
- typeof

### つまずきやすいポイント
- console.log の出力はページの画面ではなく、開発者ツールのコンソールに出る
- const の変数に再代入するとエラー（TypeError）になる
- 変数名の大文字・小文字は区別される（userName と username は別）
- 引用符で囲まない文字は変数名として扱われ、ReferenceError になる
- "42"（文字列）と 42（数値）は別のデータ型

## S02 ステージ2: 演算子

*計算・文字列の連結・比較・論理演算*

### 学習目標
- 算術演算子（+ - * / % **）で計算できる
- += などの代入演算子と、文字列の連結・テンプレートリテラルを使える
- =（代入）と ===（比較）の違いを説明できる
- &&（かつ）・||（または）・!（否定）を使える
- 文字列と数値が混ざったときの動き（型変換）と NaN を理解する

### 学習前に必要な知識
- console.log（ステージ1）
- let / const とデータ型（ステージ1）

### 教材で説明する項目
- 算術演算子（+ - * / % **）と計算の優先順位
- 代入演算子（= += -= など）と ++ / --
- 文字列の連結（+）とテンプレートリテラル
- 比較演算子（=== !== < > <= >=）と ==
- 論理演算子（&& || !）
- 型変換（Number()）と NaN

### つまずきやすいポイント
- / は整数除算ではない（7 / 2 は 3.5）
- "5" + 3 は 8 ではなく文字列の "53" になる
- 等しいかの比較は ===（= は代入）
- == は型を自動で変換して比べるため、=== を使うのが基本
- テンプレートリテラルはバッククォート（`）で囲む。"..." では ${ } が使えない

## S03 ステージ3: 条件分岐

*if / else if / else、真偽の判定、三項演算子、switch*

### 学習目標
- if / else if / else で処理を分岐できる
- 条件の順序と境界値を意識して条件を書ける
- true / false 以外の値が条件で真偽に変換されるルール（truthy / falsy）を説明できる
- 三項演算子と switch 文の基本形を書ける
- if の条件で = と === を取り違えるミスに気づける

### 学習前に必要な知識

- switch と break
- && と || の返す値

### つまずきやすいポイント
- if の条件に = を書くと代入になり、エラーにならずに常に動いてしまうことがある
- else if は上から順に調べ、最初に成り立ったものだけが実行される
- switch の case の最後に break を忘れると、次の case も実行される
- 空でない文字列は "0" や "false" でも truthy
- 「以上」と「より大きい」の境界（>= と >）

## S04 ステージ4: 繰り返し

*for、while、break / continue、入れ子のループ*

### 学習目標
- for 文の3つの部分（初期化・条件・更新）の役割を説明できる
- for と while を使い分けて、決まった回数・条件付きの繰り返しを書ける
- 合計を求めるなど、変数を更新しながら繰り返す書き方ができる
- break と continue の違いを説明できる
- 無限ループの原因に気づける
- 入れ子（ネスト）のループの動きを追える

### 学習前に必要な知識
- 変数・演算子（ステージ1〜2）
- if と比較演算子（ステージ3）

### 教材で説明する項目
- for 文（初期化 ; 条件 ; 更新）
- while 文
- 合計を求める（累積）
- break と continue
- 無限ループ
- 入れ子のループ

### つまずきやすいポイント
- i < 5 は 0〜4（5 は含まれない）。5 回まわすには i < 5、1〜5 なら i <= 5
- while の中で条件に使う変数を更新し忘れると、終わらないループになる
- 合計用の変数は、ループの前に 0 で用意する
- continue は「その回だけ飛ばす」、break は「ループ全体を終える」

## S05 ステージ5: 配列

*配列の作り方・添字・追加と削除・for...of*

### 学習目標
- 配列を作り、添字（0 始まり）で要素を取り出したり置き換えたりできる
- length・push・pop・includes・indexOf・join・slice を使える
- 範囲外の添字は undefined になる（エラーにならない）ことを理解する
- for と for...of で配列の要素を順に処理できる
- const の配列でも中身を変更できることを説明できる

### 学習前に必要な知識
- 変数・データ型（ステージ1）
- 演算子（ステージ2）
- if（ステージ3）
- for（ステージ4）

### 教材で説明する項目
- 配列リテラル [ ] と添字
- length と最後の要素
- 要素の置き換え・push・pop
- includes・indexOf・join・slice
- for と for...of
- const と配列の関係

### つまずきやすいポイント
- 添字は 0 から始まる。最後の要素は arr[arr.length - 1]
- 範囲外の添字を読んでも undefined になる（エラーにならない）
- for の条件を i <= arr.length にすると、1つ多くまわってしまう
- push は ( )、添字は [ ]。arr.push[4] のように書き間違えない
- const の配列にも push できる（再代入だけが禁止）

## S07 ステージ7: 関数

*引数・戻り値・アロー関数・スコープ・コールバック*

### 学習目標
- function とアロー関数で関数を定義し、呼び出せる
- 引数・戻り値・デフォルト引数を使える
- return と console.log の違いを説明できる
- 関数の中の変数（ローカル変数）とブロックスコープを理解する
- map・filter・forEach に関数を渡して、配列を処理できる

### 学習前に必要な知識
- 変数・演算子・if・for（ステージ1〜4）
- 配列とオブジェクト（ステージ5〜6）

### 教材で説明する項目
- function による関数宣言と呼び出し
- 引数・戻り値・デフォルト引数
- return がない関数の戻り値（undefined）
- アロー関数 ( ) => { }
- スコープ（関数・ブロックの中の変数）
- コールバック（map / filter / forEach）

### つまずきやすいポイント
- 関数は定義しただけでは実行されない（関数名() で呼び出す）
- return を書かないと、戻り値は undefined になる
- アロー関数で { } を使うと、return を明示しないと undefined になる
- return は関数を終了する（ループの中に書くと1回で終わる）
- 関数名だけを渡す（addEventListener("click", fn)）と、関数名() で呼び出すは別

## S08 ステージ8: DOM操作

### 学習目標

- querySelector・querySelectorAll で要素を取得できる
- textContent・value・classList・style で要素の内容や見た目を変更できる

## S09 ステージ9: イベント処理

*addEventListener・イベントオブジェクト・input・submit・バブリング*

### 学習目標
- addEventListener で、クリックなどのイベントに関数を結びつけられる
- 関数を「渡す」（fn）ことと「呼び出す」（fn()）ことの違いを説明できる
- イベントオブジェクト（e.target・e.target.value）を使える

### つまずきやすいポイント
